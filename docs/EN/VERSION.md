# Project version

**Casio Robotics Toolbox — version 1.2**  
**Reference date:** October 31, 2026

Version 1.2 extends the toolbox core with specialized symbolic differentiation, Jacobian construction, and Denavit–Hartenberg transformation tools. It also includes improvements to the symbolic engine, matrix operations, and expression presentation.

The Casio fx-CG50 remains the target platform. Automated PC tests complement validation, but they do not replace running tests directly on the calculator.

Version 1.2 does not introduce a mandatory dependency on KhiCAS/Xcas. Its possible use as an external engine remains an independent exploration.
